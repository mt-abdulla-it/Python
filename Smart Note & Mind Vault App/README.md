# 🧠 Smart Note & Mind Vault App

A modern, dark-themed personal knowledge management and note-taking desktop application built using **Python**, **Tkinter**, and **SQLite3**.

![MindVault Screenshot](https://img.shields.org/badge/Python-3.x-blue?style=for-the-badge&logo=python)
![SQLite Badge](https://img.shields.org/badge/Database-SQLite3-green?style=for-the-badge&logo=sqlite)

---

## ✨ Features

- 🎨 **Modern Dark Aesthetic**: Styled with Catppuccin Mocha color palette for an elegant, eye-friendly user interface.
- 📂 **Category Organization**: Categorize notes under `General`, `Work`, `Ideas`, `Code`, `Learning`, and `Personal`.
- 🔍 **Real-Time Live Search**: Instantly filter notes across titles, content body, and tags as you type.
- 📌 **Pinned & Favorite Notes**: Pin important notes to keep them on top and star your favorites for quick access.
- 📤 **Markdown & Text Export**: Easily export your notes to `.md` or `.txt` format.
- 📊 **Vault Analytics**: View total notes, word count, character count, and category distributions.
- ⚡ **Fast Keyboard Shortcuts**:
  - `Ctrl + N`: Create a new note
  - `Ctrl + S`: Save active note
  - `Ctrl + F`: Focus live search bar

---

## 🚀 How to Run

1. Navigate to the project directory:
   ```bash
   cd "Smart Note & Mind Vault App"
   ```

2. Launch the application:
   ```bash
   python3 MindVault.py
   ```

No external pip dependencies required! Uses standard Python built-in modules (`tkinter`, `sqlite3`, `os`, `datetime`).
